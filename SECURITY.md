# Reporting a security issue

Please don't report a security issue in a public issue or in the support forum.

Report it privately instead:

- with **Report a vulnerability** in the repository's **Security** tab, or
- by email to support@wpmaven.ai, with "Security" in the subject.

Please include the plugin version, what an attacker could do, and the steps that show it. We will confirm that we received your report, and tell you when the fix is released.

## Supported versions

Fixes go into the latest version of the plugin. Please check that the issue is still there in the latest version before you report it.
