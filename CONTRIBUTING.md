# Contributing to WPMaven

Thank you for wanting to help.

WPMaven's public repositories are published from a private repository at each release, so pull requests aren't merged here: the next release would replace them.

- **A bug or a question:** please post it in the [support forum on WordPress.org](https://wordpress.org/support/plugin/wpmaven/), with your WordPress, WooCommerce and PHP versions and the steps that show it.
- **An idea or a change you'd like:** the support forum is the place too. Describe what you need, and link to your fork if you wrote the change.
- **A security issue:** please don't post it in public. See [SECURITY.md](SECURITY.md).

The code is under the GPL, version 2 or later: you are free to study it, change it and share your changes, as the licence allows.
