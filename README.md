# WPMaven on GitHub

This repository holds the page of the [WPMaven organisation](https://github.com/wpmaven) (`profile/`) and the files GitHub shows in every WPMaven repository that has none of its own: how to get help, how to report a security issue, and how changes are made.

| File | What it says |
| --- | --- |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help |
| [SECURITY.md](SECURITY.md) | How to report a security issue privately |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Why pull requests aren't merged, and where changes go instead |
| [.github/ISSUE_TEMPLATE/config.yml](.github/ISSUE_TEMPLATE/config.yml) | Sends new issues to the support forum |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | The same note, on new pull requests |
